# 🎨 Artifact Gallery

Claude로 만든 아티팩트(HTML/React 결과물, 링크)를 한곳에 모아 보는 **비밀번호 보호 갤러리**입니다.
의존성 0의 단일 `index.html` 파일로, GitHub Pages에 그대로 배포됩니다.

## ✨ 기능

- **🔐 실제 암호화** — 비밀번호로 모든 아티팩트를 브라우저에서 AES-GCM(256) 암호화 (PBKDF2 25만 회 키 유도). 비밀번호 없이는 복호화 불가.
- **3가지 추가 방식**
  - 📝 Claude 아티팩트 HTML 코드 붙여넣기
  - 📁 `.html` 파일 업로드 (드래그&드롭)
  - 🔗 외부 아티팩트 URL 저장
- **관리 기능**
  - ✏️ 편집(제목·태그·내용 수정)
  - 🏷️ 태그 + 태그별 필터
  - ↕️ 정렬(최신/오래된/이름순) · 🔎 제목 검색
  - ☑️ 선택 모드 → 다중 선택 후 일괄 삭제/내보내기
- **백업/동기화 보완**
  - 암호화 백업 파일 내보내기/복원 → 다른 기기로 파일 하나만 옮기면 동기화
  - 아티팩트 JSON 내보내기/가져오기
- **안전한 미리보기** — 모든 아티팩트는 샌드박스 iframe에서 렌더링.

## 🔒 보안 모델 (꼭 읽어보세요)

- 아티팩트 **내용은 GitHub에 올라가지 않습니다.** 깃헙에는 뷰어 코드(`index.html`)만 있고, 실제 데이터는 각 방문자의 브라우저 `localStorage`에만 암호화되어 저장됩니다.
- 비밀번호는 어디에도 저장되지 않습니다. 비밀번호에서 유도한 키로 데이터를 직접 암·복호화하므로, **비밀번호를 잃어버리면 복구할 수 없습니다.**
- `localStorage` 특성상 **기기/브라우저 간 자동 동기화는 되지 않습니다.** → 메뉴의 "암호화 백업 내보내기"로 옮기세요.

## 🚀 배포 (GitHub Pages)

1. 이 저장소를 푸시합니다.
2. GitHub → **Settings → Pages** → Source를 `Deploy from a branch`, 브랜치를 `main`(또는 배포 브랜치) `/ (root)`로 설정.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 접속.

> Pages는 HTTPS로 제공되며, WebCrypto는 HTTPS(또는 localhost)에서만 동작합니다.

## 🛠 로컬에서 실행

```bash
# 그냥 파일을 열어도 되지만, file:// 에서는 일부 브라우저가 WebCrypto를 제한할 수 있어요.
python3 -m http.server 8000
# http://localhost:8000 접속
```
